# 2026-06-27 세션: JDK 버전별 차이점

## 질문

JDK 버전마다 어떤 차이점이 있을까? (이벤트 루프/WebFlux 로드맵과는 별개로, JDK 버전 자체만 떼어서 정리)

## 결론

실무 의사결정 단위는 LTS(8/11/17/21/25)다. 가장 큰 전환점은 17→21의 Virtual Thread 표준화([JEP 444](https://openjdk.org/jeps/444))이고, 21→25는 그 안정화 구간 — pinning 해소는 25가 아니라 **JDK 24**([JEP 491](https://openjdk.org/jeps/491))에서 이뤄졌다(최초 답변에서 25로 잘못 말했던 부분, 문서화 과정에서 정정). 25 자체의 신규 표준 기능은 Scoped Values([JEP 506](https://openjdk.org/jeps/506)), Compact Object Headers([JEP 519](https://openjdk.org/jeps/519))이고, Structured Concurrency는 25에서도 5차 preview([JEP 505](https://openjdk.org/jeps/505))로 아직 GA가 아니다.

## 검증 상태

- [x] 1차 출처 확인됨 (각 JEP 페이지 직접 확인)
- [ ] 코드/실측으로 직접 검증함 — 미수행. Virtual Thread pinning 해소(JDK 24)는 코드로 직접 검증하지 않았고 JEP 문서 기술만 근거로 함.
- [ ] 미검증 항목 — Structured Concurrency의 최종 표준화 목표 버전은 모름. OpenJDK 메일링리스트/JEP 후속 제안을 직접 추적해야 확인 가능.

## 모르는 것 / 후속 과제

- Structured Concurrency가 언제 GA(표준화)될지 — 다음 LTS(29, 2027.09)에 들어갈지도 모름.
- JDK 8→11 사이 비LTS(9, 10)에서 도입된 기능 중 이 노트에 누락된 것이 있는지 — 이번 세션은 LTS 전환점 위주로만 정리했고 전체 JEP를 다 훑지는 않음.
